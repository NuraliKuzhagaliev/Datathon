# CashProof — защита за пять минут

Формат 5 минут + 2 минуты вопросов указан в локальном кейсе ForteBank. Сценарий подготовлен при общем аудите 17 октября 2026; репетиция командой не выполнена. Текущие измерения и ограничения: [акт проекта](../integration/PROJECT_AUDIT.md).

## Условия реального показа

До выступления проверить API, свободную очередь, ключ, заранее завершённое дело, ZIP и Windows-приложение. Подготовить одно локально принятое положительное и одно отрицательное дело. Положительное событие нельзя заменить заданным ответом модели и назвать реальным. Пока полезное обнаружение не подтверждено, показывать инженерный прототип с явной синтетической маркировкой событий и отдельно объяснять реальные GPU-прогоны.

Не передавать реальные записи, кадры, заметки или экран дела в облачный инструмент. Публикация записи показа с конкурсным материалом требует разрешения организаторов. Ведущий управляет одним окном; второй участник следит за временем и состоянием API.

## Пять минут

| Время | Действие | Содержание |
| --- | --- | --- |
| 0:00–0:30 | Рабочее место | Проверяющему нужно связать действие, время, контекст и применимое правило. Назвать режим показа и происхождение данных. |
| 0:30–1:00 | Новый MOV | Показать upload и фактические стадии. Если открыт ранее обработанный пример, прямо это сказать. Не обещать завершение нового анализа за время слайда. |
| 1:00–2:00 | Принятое событие | Точный момент, полный исходный кадр, до/событие/после, короткий контекст. Объяснить только видимое действие. При синтетике назвать её учебным примером интерфейса. |
| 2:00–2:40 | Основание и пределы | Документ, пункт, редакция, применимость и исключения из снимка дела. Показать неоценённые условия. Не выводить юридическую виновность. |
| 2:40–3:15 | Решение и ZIP | Подтвердить/отклонить/не уверен, заметка, сохранение. Показать готовый ZIP: отчёт, исходные JPEG, источники, версии и хеши. Автоматический результат не меняется. |
| 3:15–3:45 | Отрицательный результат | Нет видимых признаков в поддерживаемой области, а не сертификат соблюдения всех банковских процедур. Техническая ошибка — отдельное состояние. |
| 3:45–4:15 | Windows | Общий React и Python-сервис, локальная модель. Утверждать запуск без сети только после disconnected-протокола. Сейчас он не выполнен. |
| 4:15–4:45 | Измерения | Назвать выборку, модель, TP/TN/FP/FN, ошибки и задержки. Не выдавать development, vendor benchmark или синтетические тесты за blind validation. |
| 4:45–5:00 | Завершение | Что работает, главный предел, конкретное следующее испытание. Закончить на 5:00. |

## Факты для вопросов

- Baseline: 28 development, 27 завершено, 1 технический сбой, TP0/TN12/FP0/FN15. Recall 0/15; precision не определена. Это недостаточное обнаружение, его нельзя скрывать числом UI-тестов.
- Qwen3.5-4B на четырёх development: TP1/TN1/FP1/FN1. После EOS-fix те же 18 структурированных ответов; медиана 105,733 s вместо 160,389 s. Полное сравнение отдельно; production не заменён.
- Реальный MOV около 28,7 MB завершался в EXE за 33,628 s до видимого результата; публичный путь с передачей занял 60,625 s. Это отдельные наблюдения, не гарантия для всех входов.
- Удержанные 12 видео не использовались для подбора. Независимость сцен и типовая ground truth не установлены. Другая камера отдельно не проверена.
- Нет cloud AI, face recognition, оценки намерения или проверки проводок. Публичный transport проходит через разрешённые пользователем Vercel/Cloudflare; согласие организаторов не зафиксировано.
- Пять коротких заданий обработаны последовательно в эксперименте. Production default — одна pending/active задача, 429 при заполнении. Пять длинных одновременно не квалифицированы.

## Резерв и репетиция

При отказе API за 10 секунд перейти к заранее открытому синтетическому demo в dev-сборке и назвать его учебным примером. Production-сборка demo не включает. При воспроизведении записи назвать её записью. Старый результат не доказывает новый анализ или офлайн-работу.

Первый прогон — все действия без таймера. Второй — ровно пять минут. Третий — отказ сервера. Записать длительность и задержки каждого. Репетиции, внешний доступ и disconnected-прогон пока не выполнены.
