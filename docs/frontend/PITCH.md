# CashProof: показ за 3 минуты

**Готовый сценарий репетиции, 17 октября 2026.** Сейчас доступен интерфейс с синтетическими примерами. Реальные результаты модели, серверный экспорт и автономный анализ ещё не подтверждены. Три минуты — выбранная длина репетиции, а не подтверждённый регламент организаторов.

## Кто что делает

- **B — ведущий и оператор интерфейса:** говорит, переключает экраны, следит за таймером.
- **A — техническая поддержка:** до выступления проверяет сервер, очередь и подготовленные дела; после основного показа отвечает на технические вопросы.
- Мышью управляет один человек. Пока A не готов, второй участник засекает время.

## Подготовка сейчас

1. Открыть `http://127.0.0.1:5173/?demo=1`, масштаб 100%. Маркировка «Синтетическое демо» остаётся видимой.
2. Проверить переходы: «Разобрать демопример» → «Сосредоточенная проверка» → «ОСНОВАНИЕ» → «Сохранить решение».
3. Вернуться в «Дела», развернуть инструкцию. Подготовить окно Windows-приложения на выборе режима.
4. Запустить отдельный таймер 3:00. Паузы между фразами нужны для чтения экрана.

## Переход к показу настоящего продукта

Менять сценарий только после соответствующего PASS в [чек-листе интеграции](INTEGRATION_CHECKLIST.md). Для настоящего показа открыть production-интерфейс без `?demo=1`. Маркировку синтетики из демо не убирать.

Человек заранее локально проверяет одно положительное и одно отрицательное дело, кадры, время и источник нормы. Материалы конкурса не отправлять в облачные инструменты или публичную запись без разрешения организаторов.

## Резервный сценарий

- **Сервер недоступен:** «Сейчас соединение с сервисом недоступно. Покажем интерфейс на синтетическом примере; это не результат работающей модели». Перейти к заранее открытой демовкладке.
- **Новый анализ не завершён:** «Обработка ещё идёт. Для демонстрации проверки откроем ранее обработанное дело».
- **Экспорт недоступен:** показать сообщение и продолжить. Не обещать готовый архив.
- **Нет автономного комплекта:** показать подключённый Windows-клиент и назвать его режим.

Видеозапись резерва сейчас не подготовлена. Если команда её делает до подключения A, использовать только синтетическое демо с видимой маркировкой. Запись всегда обозначать как запись.

## Ответы жюри

**Что отличает продукт?** Связь локального видеоанализа с кадрами, временем, источником нормы, ограничениями и отдельным решением человека. Не заявлять мировую уникальность без доказательств.

**Точность?** Только измерения A на удержанной выборке: размер, разбиение и результаты. До замеров — «Точность ещё не подтверждена». 55 проверок интерфейса не являются оценкой модели.

**Другая камера?** Только результаты отдельного испытания. Масштабирование той же записи не доказывает переносимость на другую камеру.

**Автоматическое наказание сотрудника?** Нет. Продукт помогает человеку проверять видимые признаки; не устанавливает личность, намерение или виновность.

**Сбой означает отсутствие нарушений?** Нет. Для технической ошибки отдельный статус, не отрицательный вердикт.

**Любой компьютер?** Интерфейс может подключаться к серверу. Автономный анализ квалифицируется на фактически проверенном оборудовании; целевая конфигурация — RTX 4060, 8 ГБ.

Добавить по 30 секунд: настоящий контекст; сохранённое решение и содержимое ZIP; автономный прогон; измерения и ограничения. Расширение требует работающего backend.
