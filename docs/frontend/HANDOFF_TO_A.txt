Для первого подключения нужны:

2. Операторский ключ через приватный канал или непосредственный ввод в интерфейс — не в Git и не в URL.
3. Commit backend, контракт 1.0.0, реально работающая команда запуска.
4. Статус /health/ready и готовность GPU-работника.
5. Локально проверенные положительный и отрицательный случаи; также проверим несколько событий. Реальные кадры и описания в облачный чат не присылаем.

Production: apps/web/dist, /api и /health на одном origin. UI использует POST /api/v1/analyze (202 с job_id), затем /api/ui/cases/{job_id}. GET /api/v1/jobs/{job_id} для жюри проверяем отдельно.

Критично: все обязательные поля CaseDetail, is_synthetic=false, согласованность events/model_result, стабильные event_id, неизменный исходный результат, снимок активных норм, MP4 с MIME video/mp4 и точной time_map, серверный review, реальный ZIP с MIME application/zip.

Позже для автономности нужен полный releases/backend с launch.json по схеме, моделью, Python-зависимостями и FFmpeg. Connected-сборка B сама модель не запускает.
