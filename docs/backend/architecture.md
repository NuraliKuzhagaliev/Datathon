# Implemented backend structure

`api.py` implements the frozen endpoints, key scopes and safe projections. `jobs.py` is the SQLite queue and atomic publication boundary. `worker.py` keeps model loading and inference in a supervised subprocess, separate from HTTP and optional previews. `media.py` performs full local decoding, PTS-normalized sample planning, real JPEG extraction with rotation and independently validated preview timing. `inference/model.py` loads only pinned local Qwen weights with SDPA and GPU-supported precision. `inference/pipeline.py` covers the video in overlapping windows, validates model JSON/frame IDs/predicates, verifies candidates against benign explanations, gates rules, keeps events distinct and publishes evidence. `rules.py` verifies the registry and public-source hashes. `export.py` packages results, source snapshots, raw evidence and a hash manifest.

The source contains no cloud inference client, facial recognition or audio analysis. Runtime sets Hugging Face/Transformers offline and telemetry-disabled flags, uses `local_files_only=True` and rejects missing local assets. A network-isolated launch still needs to be demonstrated; offline flags alone are not that evidence.

Initial experimental limits are 28-second screening windows with 4-second overlap, roughly 1-fps complete-video sampling, up to eight candidate verifications, 24-second candidate context and denser original-PTS sampling bounded to 32 images per call. Image inputs preserve aspect ratio and are not upscaled. These values are experiments pending GPU measurements, not latency/accuracy promises. Exceeding a completeness/resource budget is an explicit failure, never a negative prediction. Uniform sampling can miss short events and cannot prove unobserved steps; local evaluation must establish useful scope.

The web and Electron projects are B-owned. Their source was not generated or edited by this backend workstream. The API can serve B's static build from `--frontend-dir` on the same origin. Desktop uses a dynamic-port JSON handshake, a per-launch runtime key, loopback and persistent userData. A portable bundle must include runtime, packages, weights, FFmpeg and notices; packaging code must refuse absent prerequisites.
