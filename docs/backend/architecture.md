# Implemented backend structure

`api.py` implements the frozen endpoints, key scopes and safe projections. `jobs.py` is the SQLite queue and atomic publication boundary. `worker.py` keeps model loading and inference in a supervised subprocess, separate from HTTP and optional previews. `media.py` performs full local decoding, PTS-normalized sample planning, real JPEG extraction with rotation and independently validated preview timing. `inference/model.py` loads only pinned local Qwen weights with SDPA and GPU-supported precision. `inference/pipeline.py` covers the video in overlapping windows, validates model JSON/frame IDs/predicates, verifies candidates against benign explanations, gates rules, keeps events distinct and publishes evidence. `rules.py` verifies the registry and public-source hashes. `export.py` packages results, source snapshots, raw evidence and a hash manifest.

The source contains no cloud inference client, facial recognition or audio analysis. Runtime sets Hugging Face/Transformers offline and telemetry-disabled flags, uses `local_files_only=True` and rejects missing local assets. Genuine GPU/API runs passed with Python external socket/DNS calls denied. This process guard is narrower than machine-level network isolation; an OS-level offline qualification remains required.

Measured experimental limits are 14-second screening windows with 2-second overlap, roughly 1-fps complete-video sampling and at most eight candidate verifications. Verification uses a context extending 12 seconds each side, 2-fps sampling within two seconds of the candidate and wider before/after anchors. Each call accepts at most 16 frames, 14,000 input tokens and 768 generated tokens; image pixel budgets are 65,536 for screening and 131,072 for verification. Images preserve aspect ratio and are not upscaled. Earlier larger visual inputs exceeded the deadline on the longest supplied video; this configuration completed that video in 173.01 seconds. These are experiments, not accuracy promises. Exceeding a completeness/resource budget is an explicit failure, never a negative prediction. Uniform sampling can miss short events and cannot prove unobserved steps; local evaluation must establish useful scope.

Each case saves `configuration.json` with inference settings and SHA-256 of every Python implementation file. Exports include that snapshot, exact per-case legal source bytes, original input hash, model revision, evidence hashes and the immutable automatic result alongside separate human reviews. Terminal result publication is atomic. Preview and export preparation cannot alter the automatic verdict.

The web and Electron projects are B-owned. Their source was not generated or edited by this backend workstream. The API can serve B's static build from `--frontend-dir` on the same origin. Desktop uses a dynamic-port JSON handshake, a per-launch runtime key, loopback and persistent userData. A portable bundle must include runtime, packages, weights, FFmpeg and notices; packaging code must refuse absent prerequisites.
